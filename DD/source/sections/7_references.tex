\section{References}

The following softwares were used to produce the RASD and DD of the Best Bike Paths project: 
\begin{itemize}
    \item All diagrams were made using the Draw.io 29.2.9 software.
    \item All mock-ups were made using the Figma 125.11.6 software.
    \item Overleaf web application for document writing and rendering.
\end{itemize}

Also, generative AI models were used to refine sentences and elevate writing style inside the DD and RASD documents and to check how to model some aspects of the BBP software in UML. Also LLMs were used to overcome some difficulties with \LaTeX\hspace{1mm}  itself, as it sometimes produces cryptic error messages only OCaml programmers can understand. More specifically, the Gemini Pro and ChatGPT models were used, but all the thinking process and the final design and implementation decisions were made by humans. All the outputs of these tools were verified, further refined and integrated with the documents.
